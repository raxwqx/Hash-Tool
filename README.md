
# 🔐 Hash-Tool

Basit ve hafif bir Python hash oluşturma aracıdır.

Bu proje, Python `hashlib` modülünü kullanarak metinlerden farklı hash değerleri üretmek ve temel hash algoritmalarını öğrenmek amacıyla geliştirilmiştir.

## ✨ Özellikler

- 🔑 MD5 hash oluşturur
- 🔐 SHA256 hash oluşturur
- 🛡️ SHA512 hash oluşturur
- 🐍 Python `hashlib` modülünü kullanır
- ⚡ Basit ve kullanımı kolaydır
- 🧪 Eğitim ve kontrollü lab ortamları için tasarlanmıştır

## 📋 Gereksinimler

- Python 3

Python sürümünü kontrol etmek için:

```bash
python3 --version
```

## 🚀 Kullanım

Programı çalıştırmak için:

```bash
python3 hash_tool.py
```

Program senden hash oluşturulacak metni ister:

```text
Hashlenecek metni gir: hello
```

Ardından MD5, SHA256 ve SHA512 sonuçlarını gösterir.

## 📌 Örnek Çıktı

```text
[+] Hash sonuçları:

MD5:    5d41402abc4b2a76b9719d911017c592
SHA256: 2cf24dba5fb0a30e26e83b2ac5b9e29e...
SHA512: 9b71d224bd62f3785d96d46ad3ea3d73...
```

## ⚠️ Önemli Not

Hash işlemleri şifreleme ile aynı şey değildir.

Hash fonksiyonları tek yönlü veri dönüşümleri için kullanılır. Özellikle MD5 ve SHA256 gibi algoritmaların güvenlik açısından kullanım alanları birbirinden farklıdır.
